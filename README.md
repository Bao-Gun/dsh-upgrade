# dsh-upgrade

自用的 DSH 插件：给 dsh web 加升级能力，替代每次「手动升级全局 dsh 包 + 手动重启 dsh web」这套手工动作。只给一个人用。

## 跑起来

```bash
# ⚠️ 待补全：安装 / 启动命令 —— 要补成两条能直接粘贴执行的命令（例：`npm install` / `npm run dev`）；补在：本代码块，删掉这行注释
```

## 检查

```bash
bash check.sh
```
